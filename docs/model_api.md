# Описание структуры API моделей

Обязательная ручка:

- `POST /process_audio`
  - **Назначение:** принять аудиофайл и вернуть текстовую транскрипцию.
  - **Формат запроса:** `multipart/form-data` с полем `file` (одно аудио). Поддерживаемые расширения: `.wav`, `.mp3`, `.opus`.
  - **Формат ответа:** `200 OK` и JSON`{"text": "..."}`. При ошибке обработки вернуть `4xx/5xx` с ключами `error` и `detail`.
  - **Ограничения:** валидация типа MIME обязательна.


- При реализации на Python использовать FastAPI.

Порт HTTP-сервиса задаётся переменной окружения `WHISPER_BACKEND_PORT` (см. `.env`). Базовый адрес ручек: `http://localhost:${WHISPER_BACKEND_PORT}`.
